# 07 — UI：《Saddle & Spoke》

> 闸 A 写 §1–4；§5 之后只在实测后补。基线视口 1440×900，1px = 1px。

## 1. 风格预设：*车间的账本*（Workshop Ledger）

整页是一间**修车铺的墙 + 台面**。墙是纸（米白、粗纤维），台面是深墨（近黑）。所有装饰都来自车间里真实存在的东西：工单纸、价目表、零件标签、铅笔注释、黄铜聚光。**没有卡片阴影、没有渐变按钮、没有玻璃拟态**——它是纸和铁，不是 SaaS。

| Token | 值 | 用途 |
|---|---|---|
| `--paper` | `#f3eee4` | 墙（左半屏）底色 |
| `--paper-2` | `#e9e1d2` | 工单纸、贴纸底 |
| `--ink` | `#17140f` | 台面底色；纸上正文 |
| `--ink-2` | `#3b352b` | 纸上的次要文字 |
| `--ink-3` | `#6d6353` | 注释、等宽小字 |
| `--rule` | `#cfc4b0` | 分隔线、蓝图网格 |
| `--brass` | `#a8621f` | 聚光圈、唯一的主按钮 |
| `--brass-soft` | `#d9a05a` | 聚光晕、引线 |
| `--agent` | `#2b5f63` | trace、agent 名、连接线 |
| `--alarm` | `#a3352a` | 被拒、unknown、失败用例 |
| `--ok` | `#4f6b3a` | 通过、confirmed |
| `--console` | `#100e0b` | 台面最底 |

- **字体**（全部随包，不外链）：标题 `Fraunces`（可变，opsz 9–144，wght 500/600）；正文 `Inter`（400/500/600）；等宽 `IBM Plex Mono`（400/500，只用于 trace、零件号、金额、回执）。纸上的正文不小于 15px，等宽不小于 12.5px。
- **字号六级**：13 / 14 / 17 / 21 / 34 / 64。纸面大标题用 Fraunces 64/0.98，字距 -0.02em；等宽标签一律大写、字距 0.08em。
- **形状**：纸上只有两种圆角：0（工单、贴纸用切角）与 2px（零件标签）。台面上圆角 3px。分隔用 1px 实线或 2px 点线，**不用阴影做层级**。
- **颜色纪律**：黄铜一屏最多三处（当前聚光圈、主按钮、当前选中的工位）。深青只出现在 trace 与 agent 名，不用于装饰。红色只在「被拒绝 / unknown / 失败用例」出现。
- **动效**：聚光圈移动 420ms `cubic-bezier(.22,.61,.36,1)`，同时引线（一根 1px 的 `--brass-soft` 直线）从标签连到零件；trace 新行 160ms 淡入 + 2px 上移；`prefers-reduced-motion` 时全部改成 0.01ms 直切。

## 2. 尺子 —— 什么算好

| 参考 | 学哪一点 | 不学什么 |
|---|---|---|
| **Stripe**（stripe.com 的产品页） | 界面本身就是插图：把真实产品的一小块按 1:1 画出来，而不是画一张示意图。 | 它的营销式大留白（我们要信息密度）。 |
| **Linear**（linear.app） | 高密度不等于吵：靠 1px 线、字重与留白分三层，不靠卡片和阴影。 | 它的深色渐变与光晕。 |
| **Raycast** | 工具本身就是主角，界面截图可以直接当主视觉。 | 它的图标墙。 |
| **Family**（family.co） | 纸感 + 一个字重很重的手写体 + 极少的颜色，亲切但不软。 | 它的玩具感插画。 |
| **Teenage Engineering** | 技术线稿 + 全大写等宽标签 + 对得极准的网格，冷但清楚。 | 它的极简到不好用。 |
| **Notion Calendar（Cron）** | 时间/排期用真实的网格表现，不换成漂亮的时间轴插画。 | 它的纯黑白（我们要黄铜）。 |

过线的意思：把主屏和这六件混在一起盲排，第一眼能停下，并且说得出「这是修车铺的柜台，右边是在干活的 agent」。

## 3. 一个记忆点

**agent 说到哪颗零件，车上的光就落到哪颗。**

不是聊天框旁边贴一张图，也不是把零件名加粗：运行时每次执行 `highlight_part`，主屏那辆线稿车会**暗下去半档**（`opacity: .55`，300ms），一颗直径 128px 的黄铜光圈从当前位置移到那颗零件上，光圈内恢复原亮度，一根 1px 的引线从零件拉到右侧一行等宽注释：

```
REAR DERAILLEUR · SHIMANO RD-M310
```

零件本身同时加 1.5px 的 `--brass` 描边。整页只有这一处会「动」，别的一切（工单、trace、状态条）都要安静。

其余一切都要让路：聚光圈出现时不做弹窗、不震屏、不换页；车不动、镜头不推。**一个动作，一个焦点。**

│     answers your agent.”                   │  │ 同意卡 / 确认卡 / 回执 │  │

│  · 车下 24px：一行注释（等宽 12.5px）        │  │ 建议 chips（3 个）     │  │
│  · 左下角：工单纸 320×196（贴角 -2°，有齿孔） │  └────────────────────┘  │

├───────────────────────────────────────────┴──────────────────────────┤
│ status 40px   local planner · hop 1/4 · calls 4/12 · origins 1 · ⟨session⟩│
└──────────────────────────────────────────────────────────────────────┘

- **车（SVG）**：侧视线稿，1.6px `--ink` 描边、`--paper` 填充；五个可高亮零件组各自带 `data-part`：`rear_derailleur`、`chain`、`brake_pads`、`bottom_bracket`、`rear_wheel`。非聚焦时整车 `opacity .92`；有聚焦时整车 `.55`，聚焦组 `1`。
- **聚光圈**：直径 128，`--brass` 1.5px 描边 + 8% 填充；外面一圈 12px 的 `--brass-soft` 20% 晕。中心 = 该零件组的 bbox 中心；标签在光圈右上方 18px，等宽 12.5px，两行（零件名 / 零件号）。
- **工单纸**：320×196，`--paper-2`，左边缘一排 4px 齿孔（点线），标题 `JOB CARD`（等宽、大写、字距 .08em），下面四行：`FOR` / `WORK` / `PRICE` / `READY`，值用 Fraunces 21。未成单时整张是「空白工单」，只有一条横线。
- **台面**：`--ink` 底，消息正文 Inter 14.5/1.55 `#e8e2d6`；`agent` 名用等宽 12.5 `--agent` 大写；trace 行是「等宽 12.5 + 左侧 6px 状态点」，缩进表示委派深度（每层 12px）。同意卡/确认卡是 `--paper-2` 的纸片（在深色台面上唯一亮的东西），圆角 3，边框 1px `--rule`。
- **输入区**：单行 input（Enter 发送），右侧方形发送键 40×40（`--brass`）。下面 3 个建议 chips（14px，1px 边框，hover 变 `--paper-2`）。
- **状态条**：40px，`--console` 底，等宽 12px，`--ink-3` 字；右侧 `⟨session⟩` 打开 session 抽屉（router、contacted origins、budgets、sly_data 允许/拦截）。

**响应式**：
- ≥1280：上述规格。
- 1024–1280：台面缩到 380，车缩放 0.78。
- <1024（窄屏/手机竖屏）：上下两段——上段墙（高度 56vh，车缩放 0.62，标题降到 34px），下段台面（剩余高度）；状态条改成两行 56px。

### 5.1 已知弱点与改法（下一场照改，不回头改这一版）

评委二的原话是「it is lopsided, because the heavy black agent console takes a third of the
page and pulls the eye away from the pale sheet, leaving the headline and body copy crammed
into a narrow strip with small type」。这条成立：1440 宽时纸面 1020、台面 420，台面的黑块
确实比纸面重，标题只剩 58ch 的宽度。

下一场先试这三条，按序：

1. **台面收窄到 380**，把省下的 40px 给纸面；标题行宽随之到 ~64ch。
2. **纸面提亮一档**（`--paper` 从 `#f3eee4` 到 `#f7f3ea`），让黑块的白字对比更强、纸面更"亮"，
   视觉重量从"黑块重"改成"黑块深"。
3. 标题字号在 ≥1440 时放到 62，lede 收到两行。

三条都不改结构，只调比例；下一场（或本作二版）做一次盲排复核。

### 5.2 封面的一条实测

1500×1000 的封面直接用整页截图（`scripts/cover.mjs`，不打任何补丁），因为试过两种"重排"：
只留纸面会让车变小、留白变大；缩小加光圈会与车架重叠。**封面就用产品原样**，比任何重排都稳。

Bellwether Parts · trade only · Sheffield

A trade counter that answers shops, not chatbots.

This page publishes one agent network, bellwether_parts. A bicycle shop's page can load it and run it in the visitor's own browser: no account, no key, no server of ours in the middle.

It answers three things about one part: how many are on the shelf, the lead time, and the trade price.

Where this lives

The network definition is a static file next to this page. The runtime is the caller's — the shop's page, on its own origin — which is why a trade counter needs no application server to be part of the agentic web.
